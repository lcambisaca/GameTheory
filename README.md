# GameTheory BS Project
Simulated 4-player strategic behaviors in the bluffing card game “B.S.” using payoff matrices and Nash equilibria to analyze optimal bluffing and calling strategies.
Implemented a Moran process with mutation and derived the corresponding replicator dynamics to visualize expected evolutionary trajectories over time.
Computed best responses and mixed strategy equilibria, showing that players tend to adopt truth-telling and reactive calling strategies.
